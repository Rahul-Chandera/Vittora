# R1 — PDF export for Monthly Overview & Annual Summary

**Branch:** `feature/r1-pdf-reports` · **PR into:** `develop` ·
**Review tier: B** (post-merge review) · **No dependencies**

## Context

Export today is CSV-only (`ExportFormat` in
`Packages/VittoraCore/.../DataExportService.swift`). Reports render in
SwiftUI (`Features/Reports/`). Goal: shareable, printable PDFs of the two
most-asked-for reports.

## Scope

1. A `ReportPDFRenderer` (app target) that renders a purpose-built
   SwiftUI report layout to PDF via `ImageRenderer` — A4 portrait,
   header (report title, period, app name), page numbers, footer note
   "Generated by Vittora — data stays on your device". Do not screenshot
   the live screen; lay out a print-clean variant of the report (no
   toolbars/buttons, charts sized for the page).
2. Wire a Share/Export button on **Monthly Overview** and **Annual
   Summary** report screens → renders PDF → `ShareLink`/share sheet
   (iOS) and save panel (macOS — user-selected-file entitlement already
   present).
3. Currency, dates, and numbers formatted with the existing formatters;
   multi-page output when a year's table overflows one page.
4. Unit test: renderer produces a non-empty multi-page PDF for a seeded
   12-month dataset (assert page count ≥ 2 and PDF magic bytes).

## Non-goals

Custom report builder PDFs, CSV changes, Excel, email integration,
scheduled exports.

## Acceptance criteria

- [ ] Export button on both reports produces a PDF that opens in
      Preview/Files with correct data, charts, and pagination.
- [ ] Works on iOS (share sheet) and macOS (save panel).
- [ ] Long datasets paginate; nothing clipped.
- [ ] Unit test passes; `make test` green.

## Verification steps

1. Attach a generated sample PDF (demo dataset) to the PR.
2. Screenshots of the export flow on iPhone + Mac.
3. `make test` summary.
